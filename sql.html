A free SQL playground in your browser

This board works like an online SQL fiddle. Write your CREATE TABLE and INSERT statements, or import a CSV, then write any query and run it. Each run starts from a fresh database built from your tables, so you can experiment without breaking anything.

What SQL does it run?

It runs SQLite, so joins, GROUP BY, window functions like ROW_NUMBER and LAG, common table expressions and date functions all work. Nothing is sent to a server.

Can I share my work?

Yes. Copy link puts your tables and query into the address, so anyone who opens it sees exactly what you wrote.
